# DECISIONS.md

## DEC-001 — Commencer sans API sportive payante
Date : 2026-08-29
Décision : V1 fonctionne sans API sportive payante.
Raison : réduire les coûts et la complexité avant validation du trafic.

## DEC-002 — Documentation comme source de vérité
Date : 2026-08-29
Décision : PROJECT.md, ROADMAP.md, ARCHITECTURE.md, TASKS.md, DECISIONS.md et CHANGELOG.md sont la mémoire durable du projet.
Raison : permettre de changer d'IA sans perdre la chronologie ni l'architecture.

## DEC-003 — Développement par petites tâches
Date : 2026-08-29
Décision : aucune fonctionnalité n'est terminée sans test et documentation.
